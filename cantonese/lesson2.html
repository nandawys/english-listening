第 2 课 · 入声 -p / -t / -k

发出日期约 2026-11-05。目标：听出并跟读塞音韵尾，不在后面加元音。

状态：已发出 · 跟读反馈待回复

入声是什么

粤语有以 -p / -t / -k 收尾的音节。收尾是不除阻（unreleased）的塞音：口腔堵住就停，不要再发出额外的元音（别说成 「si-ke」）。

调类提示：sik1 / sik3 / sik6 对应第 1 课 si1 / si3 / si6 那几个调类，只是更短促。
